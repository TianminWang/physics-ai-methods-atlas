# v0.8 · 全宽方法演化 DAG 的布局与导航

> **保持已确认的三阶段研究主轴和一份权威方法知识库，只优化展示。** 本版不新增、不合并、不伪造任何学术方法关系。

## 一、为什么默认画布只显示一部分方法？

目前知识库收录的具体方法比已整理的“扩展/融合”演化关系多得多。为避免把大量缺少演化边的节点散落在主画布、稀释真实谱系：

- **主画布：** 只展示至少参与一条 `extends` 或 `combines` 关系的方法。使用 Graphviz 对这些真实关系进行分层与紧凑排列。
- **谱系待完善：** 尚未记录扩展／融合边的其他方法（**仍然属于同一份知识库**）。它们可能有分类关系、论文、优先阅读和广泛应用；通过下方折叠区域与搜索可以直接访问。
- **分类／对照：** 属于独立的关系类型，可根据需要叠加显示，但不参与方法演化的层级排序。
- **连通分量：** 主画布上允许存在多个彼此不连通的真实方法发展分支，点击分支导航可直接定位，不为可视化连通而增加伪造的学术关系。

这是一种**视图折叠策略**，不是说没有演化边的方法没有学术价值。

## 二、配色和线型

方法节点颜色对应 **主要视觉技术范式**：传统数值／优化、统计／概率推断、机器／深度学习、物理–数据混合。方法本身仍可以属于多个学术家族。

方法扩展与融合边沿用 **三阶段配色**：

- 第一阶段“物理建模与正向问题” → 蓝色
- 第二阶段“反问题求解与未知信息推断” → 紫色
- 第三阶段“个体化预测、干预与闭环更新” → 青绿色
- 暂无法确认主要研究阶段 → 中性灰

实线为 `extends`，较长虚线为 `combines`；灰点线是 `specializes`，**不是历史进步**。边点击后会展示完整技术变化、瓶颈、适用边界和支持论文。

## 三、完整交互体验

- **全宽 DAG：** 默认不占用固定详情栏，画布高度随浏览器高度变化。
- **详情抽屉：** 点击任意可见方法／关系，右侧覆盖式打开详情。可关闭，也可点击“固定”停靠，使画布相应缩窄。
- **全屏模式：** 仅展开 DAG 为整个浏览器窗口，退出后恢复页面布局。
- **小地图：** 标出全部真实演化分支和当前视口；可通过点击或拖动快速定位，也可隐藏。
- **连通分量导航：** 点击分支标签聚焦对应的演进关系。
- **前驱／后继路径：** 选中方法或演进边后，按需突出相关的扩展／融合链；与分类线和对照线严格分开。
- **全局搜索：** 搜索所有权威方法，包括不在主画布上的谱系待完善节点；选中后可查阅其原始论文及优先阅读。
- **主轴筛选：** 从三大研究阶段出发，突出直接与家族级相关方法、以及针对该阶段瓶颈的演进边。没有映射的节点淡化，不被删除。
- **中文默认、英文可切换**；选中学术关系后显示原始论文和权威记录链接。

## 四、离线查看与重建

在 GitHub Actions 的 **Validate atlas data → 最近成功构建 → Artifacts** 下载 `atlas-fullwidth-dag-v08`。解压后直接打开 `index.html`，不需要 Python 或服务器。

开发者可从仓库根目录构建：

```bash
python -m pip install -r requirements-dev.txt
python -m scripts.build_v08 --site build/viewer-v08
```

构建机需要 Graphviz 和中文字体；用户查看离线网页时不需要这些依赖。源码位于 `scripts/build_v08.py` 和 `viewer-v08/`。Chrome/Chromium 的桌面与移动端检查会生成对应截图附件。

## 五、这版的边界

v0.8 解决的是**可读性、交互与空间利用**，不是完整学术谱系的终点。现有研究在真实方法演化关系上的覆盖仍然有待继续扩充。

后续进入正式 GitHub Pages 前，可以继续评估更大规模方法图谱的布局性能、键盘/触屏可访问性、详情抽屉宽度和全局导航体验。

**Landmark 是论文对某一方法的学术贡献；Start Here 是非强制的少量优先阅读建议。**
