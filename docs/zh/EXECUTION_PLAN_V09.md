## 1. 核心目标与非目标

Atlas 从**可信学术文献与专著集合（Scholarly Corpus）**中逐步归纳数学、数值计算、反问题、Physics AI、生成模型、世界模型及相关生物医学工程方法的概念、理论和真实关系，再构建交互式知识平台。

- **先来源、再知识体系。** 不把旧 61 方法、34 家族、19 Capability 当作固定目标；它们只是原型参考。
- **方法学广度与生医工实用性并重。** 广泛吸收数理/ML 理论与方法创新，同时重视生物医学方法改进、工程系统设计和可信临床/患者数据验证；不要求每篇生医工论文都有通用理论突破。
- **多轴关联，不强制互斥分组。** 检索主题、应用场景与证据成熟度是不同维度；一篇来源在 Corpus 中只存一次，可标注多个方法主题和应用主题。
- **不追求引文数、节点数或主 DAG 连通度。** 不为填补图谱或满足方向配额放低质量门槛。
- **广覆盖 + 分批深入。** 首先跨领域检索、掌握经典源流与现代代表研究，再按主题审核/归纳并反向补查，绝不把“找齐全部论文”作为任何工作开始的前置条件。

## 2. B1 系统检索组织：两条并行轴

### 方法学轴（仅检索标签，绝非既定本体）

| ID | 范围 |
| --- | --- |
| M1 | 数学建模与数值计算：ODE/PDE、离散、误差/稳定性、ROM |
| M2 | 确定性反问题与优化：适定性、可辨识性、正则化、最小二乘、伴随与灵敏度 |
| M3 | 概率与统计反问题：Bayesian、MCMC、VI、SBI、UQ、模型失配 |
| M4 | 动力系统与数据同化：KF/EnKF、4D-Var、状态估计与系统辨识 |
| M5 | Physics AI / 科学机器学习：PINN、神经算子、可微模拟和物理约束代理 |
| M6 | 生成模型与生成式反问题：VAE、Flow、Diffusion、生成先验与后验 |
| M7 | 世界模型、控制与决策：latent dynamics、MPC、最优控制、model-based/offline RL |
| M8 | 视觉与几何计算：重建、分割、3D/4D、多模态、几何学习 |

### 生物医学应用轴（与 M1–M8 正交，可多选）

| ID | 范围 |
| --- | --- |
| A1 | 医学影像/表征：DSA、CTA/CCTA、OCT、IVUS、医学图像重建与分析 |
| A2 | 生物医学数值建模：血流动力学、0D/1D/3D、边界条件、患者特异几何 |
| A3 | 生理参数/功能推断：FFR、iFR、QFR、压力流量、反问题、状态估计 |
| A4 | 医学 AI / 快速预测：代理模型、医学神经算子、泛化及验证 |
| A5 | 干预模拟与决策：virtual PCI/virtual stenting、反事实预测、规划 |
| A6 | 医学数字孪生：患者特异性动态预测、UQ、纵向同化与反馈 |

这两条轴只是帮助**检索与检索后标记**。可能存在 M8+A1、M5+A2+A4 或 M2+M3+A3 等交叉；不要求每一篇都同时具有方法轴和应用轴标签。非冠脉的高质量医学研究按迁移价值决定是否进入候选。

### 检索手段

1. **来源定向：** 按已批准的 V1/V2 期刊、主会 proceedings 和出版社分别检索；V1/V2 只影响查找顺序，不决定准入。
2. **经典源流：** 借助领域公认的专著和权威综述回溯关键原始工作，避免只看最新 5–10 年。
3. **引文网络：** 顺着代表论文的参考文献与后续独立验证发现源头、改进、失败模式及适用条件。
4. **应用侧并行：** 生物医学工程/医学 AI（TMI、MedIA、MICCAI、IPMI、TBME、JCP/CMAME 交叉）以及冠脉临床和医学工程（JACC、Circulation、European Heart Journal、专门的 CT、介入、血流期刊）同步检索，不留到最后再“套应用”。
5. **清单外例外：** 不封闭来源；可信经典、领域公认工作和特殊预印本按正式准入政策核实。

记录每一批实际查询的**日期、检索源、关键词、目的、命中来源链接**与已知限制。首轮为**非穷尽的可追溯发现工作**，不能称“系统综述完成”或暗示所有相关文献已覆盖。新发现与旧 58 篇/12 本都按同一准入门槛，做 DOI/书目版本去重。

## 3. B2 质量审核：简洁结论，明确证据

只使用正式政策的 **准入 / 待核查 / 不准入**。

- **基础核验：** 题名、作者、年份、DOI/永久链接、具体刊物/会议 Track/出版社、出版版本、领域相关性。
- **实质核验：** 研究的原创理论、算法、工程方法、严谨比较、独立验证或可靠综合；检查数学/物理假设、实验设计、结果边界、重要更正/撤稿。
- **经典/预印本/开放教材：** 按专门例外处理，保留特殊准入的独立证据、限制与复核理由。
- **医学证据层级：** 模拟可行性、患者数据、外部验证、前瞻性决策/结局分开记录；不把算法可用性自动提升为临床有效性。

**仅发现书目和摘要 ≠ 学术质量审核通过。** B1 的候选一律先标记“待核查”，不能自动进入 `data/papers/` 或产生正式图谱节点。即使来源是顶会或经典也必须审核。

## 4. B3 知识提取与跨文献归纳

对通过准入的来源，记录：问题、变量与数学/物理假设、核心机制、基于何种先前研究、具体创新、适用条件、失败模式、验证类型、原文证据定位。书籍优先定位具体章节/版本。

随后进行跨来源对照、合并同义概念、明确知识层级，**先形成候选知识主张，后决定是否有独立理论/方法节点**。保留分类/包含、真实历史演进、训练/推断机制借用、科研任务与证据适用范围的差异；不能根据论文共同关键词或发表年份创造演进边。

对缺失源头、争议关系、模型适用条件，循环返回 B1/B2 定向补查。审查旧 11 种方法类型、34 家族、19 Capability、三阶段主轴的合理性，而不是强制复用。

## 5. C 数据库与 D 交互界面

同一个来源集合支撑同一个经审核的知识数据库（不复制实体）：

- **来源层（Corpus）：** 论文/专著/版本、准入决定、位置定位和审计证据。
- **知识层：** 理论/模型/算法/机制/方法家族/科研问题及有证据的关系。
- **视图层：** ①知识分类 Taxonomy、②真实方法演进 Lineage、③科研问题与应用 Problem Pathway、④学术文献库 Scholarly Library。

界面应在四个入口间相互导航：从临床问题找到方法，从方法找到原始论文，从演进边找到具体证据，从文献找到相关概念。可重用 v0.8 的全宽 DAG、搜索、双语、缩放、小地图、抽屉、局部聚焦，但新知识不服从旧布局；未经审查的旧数据不默认当正式成果呈现。

## 6. 阶段执行与验收

| 阶段 | 交付内容 | 状态 |
| --- | --- | --- |
| **B1：跨领域发现** | 方法学 × 应用轴的检索日志、论文/综述/专著候选清单、来源链接和去重 | **已启动（首批候选记录见 `research/b1/`）** |
| **B2：准入审核** | 逐篇/逐本结果、准入理由与限制、可用正式 Scholarly Corpus | 未启动 |
| **B3：原文归纳与补查** | 技术主张、独立概念候选、关系证据位置、缺口清单和补充检索 | 未启动 |
| **C：正式知识数据** | 可验证的概念/关系、数据迁移与原型隔离 | 未启动 |
| **D：四视角交互** | 分类/演进/问题/文献库共享数据的可用界面，桌面移动端测试 | 未启动 |
| **v1.0** | 稳定发布、学术审校和维护机制 | 未启动 |

验收不以候选条数决定：B1 需说明覆盖范围与空白，B2 需有正式可靠准入记录，B3 需提供原文定位，C 需通过学术关系与数据一致性检查，D 需保证搜索与切换到来源可到达。

### B1 首批实践边界

为及时验证检索与记录格式，先用**可追溯的小批真实发现**覆盖多种方法学和应用标签、经典与现代、论文与书籍。该批只是更大范围检索的起点，**既不是推荐阅读清单，也不是已经通过准入的正式 Corpus**。

每批提交检索日志与候选数据，记录尚未覆盖的空白。待跨领域基础覆盖和来源审查均达到可以开始归纳的程度，再实施 B2/B3；绝不以“数百篇”的假设数量制造形式配额。
