# Corpus-first v1：全域文献与专著基线建设协议

> **批准日期：2026-11-26** · **状态：正式执行中（首轮全域检索/质量审核尚未完成）**
>
> 本文替代此前 [EXECUTION_PLAN_V09.md](EXECUTION_PLAN_V09.md) 中的“分批检索、分批归纳或创建方法节点”的执行顺序；不改变 [SOURCE_ADMISSION_POLICY.md](SOURCE_ADMISSION_POLICY.md) 的学术质量门槛。详见 [Issue #13](https://github.com/TianminWang/physics-ai-methods-atlas/issues/13)。

## 1. 一条先后顺序

**范围固定的全域检索 → 候选文献去重与完整性核查 → 学术质量准入与覆盖审计 → 冻结首版 Scholarly Corpus v1 → 全域跨文献归纳与知识本体设计 → 正式知识数据库 → 四视角交互界面。**

*在 Corpus v1 冻结前，不正式建立、迁移、扩展方法节点/家族、演化关系或正式可视化知识图。* 即使检索过程内部为便于操作分成若干查询与审核工作单元，也只累计**同一个 Corpus 候选库**，不按工作单元生成部分本体。

这条要求的目的是减少早期小样本造成的理论谱系缺失、概念误分类和反复迁移。

## 2. 从零建立学术基线，不以旧图谱为线索

- `data/` 的旧61方法、34家族、58论文、12专著、530关系及 `audits/v09/` 的11种分类/19 Capability **全部解除学术结构约束**；**不得**用它们作为检索方法清单、覆盖配额、入选名单或验收依据。
- `research/b1/candidates-2026-11-26-01.json` 之前的26条是探索性历史结果，不自动成为本次 Corpus v1 的候选，也不赋予优先待遇；如独立检索再次发现同一研究，走新流程。
- **保留工程资产**：旧数据/界面/Schema/验证器可以仅作为实现参考与回归对照。为避免破坏历史原型，本阶段不删除文件；正式成果将建立独立的学术来源区与验证流程，切换后再处理旧数据。
- 不预设最终方法种类、家族数量、研究能力层数或图谱连通性。

## 4. 先协议，后广域发现

检索同时使用以下互补渠道：

1. **来源优先检索**：在 [准入政策](SOURCE_ADMISSION_POLICY.md) 所列 V1/V2 期刊/会议进行主题检索；核实会议 main track、proceedings、特殊发表类型。V1/V2 不是收录白名单或论文分级。
2. **学术数据库与权威注册表**：Crossref/OpenAlex、PubMed、专业出版社网站、PMLR、NeurIPS/ICLR 等主会官方论文集、SIAM/Cambridge/Springer 等出版社、可用的其他索引。不同数据库对早期论文/书籍收录不全，应交叉检索。
3. **专著与权威综述引文**：回溯理论源流、定理和重要方法类别，按原书章节识别经典原创文献，不把综述误记为算法发明。
4. **前向/后向引文追踪**：核查代表研究的源头、被独立改进/复用、系统比较/失败模式，以及临床验证的发展链路。
5. **交叉领域检索**：M 轴和 A 轴的交叉研究、可迁移的医学成像方法及新理论；不要求机械完成每个 M×A 的笛卡尔积。
6. **清单外例外**：可靠的经典与重要专题研究允许按质量门槛提名，不能因来源表未列出就排斥。

每条可复核检索记录至少包括：UTC/本地检索日期、检索界面/数据库、查询表达式、方向、过滤条件、结果数（可获得时）、候选链接、实际能否访问全文、局限与下一轮补充。严禁将仅有网页搜索结果的非穷尽发现记录冒充系统综述或“所有研究已覆盖”。

## 5. 候选去重、出版状态和审核

- **唯一作品**：DOI 优先，辅以规范化题目/作者、arXiv ID、ISBN/书籍版本；正式期刊/会议版与预印本对应同一研究作品的多个版本，不重复当独立创新。若原作/扩充版的贡献实质不同才单独说明。
- **书目核验**：研究类型、正式主会/Workshop/期刊、出版社、年份和版本；查出版状态、重大更正/撤稿。
- **实质质量准入**：只用“准入 / 待核查 / 不准入”，按可靠审稿、主题贡献、数学与物理假设、实验/临床证据、局限审查；允许文献类型适当不同的核验深度，但“摘要看起来很好”不算通过。
- **经典/预印本/开放教材**：适用政策中的特别准入例外与记录要求。
- **医学证据边界**：数值/体外、回顾性患者、独立外部、前瞻性/随机试验不混用；不以方法学发表地位证明临床疗效。
- **未完成核验的来源只能留候选池**，不得进入正式 Corpus v1。

## 6. Corpus v1 的停止与冻结标准（拒绝假定“全世界已穷尽”）

这次“尽可能完整”的可执行含义是：**在上述清楚限定的领域和截止日期内，通过可追溯、跨渠道、反复补查的系统检索形成覆盖充分的首版高质量基准**。不是声称所有合格论文都已被找到。

只有具备以下证据，才能冻结首版：

1. M1–M8 和 A1–A6 各主要主题均有实际执行的检索记录，且覆盖历史经典、代表性现代发展、可靠综述/专著（如适用）、重要比较/反证与医学工程验证；未覆盖主题明确解释。
2. 每个主题至少采用不同类型的两个发现途径（例如官方来源主题检索 + 权威综述/专著引文回溯），并记录搜索日期及筛选结果；不是简单在各主题随意放一篇文章。
3. 候选研究已统一去重并完成必要的出版状态/质量审核，待核查来源单列，不混入正式 Corpus。
4. 做**覆盖矩阵审计**：主题 × 年代/经典-现代 × 原创/综述/教材 × 研究性质/验证范围，并公开重要缺口与仅凭摘要无法判断的限制。
5. 最后补充检索若仍不断发现未收录的重要源头或关键研究线，说明尚未饱和；可用持续若干轮独立扩展不再频繁出现新增关键工作，作为“足以开始建模”的证据，但不使用固定论文数量或引用量阈值替代专家审查。
6. 发布版本化的 `Scholarly Corpus v1`，包含：**检索截止日期、实际检索日期范围、检索协议和日志、去重轨迹、质量准入结果、例外依据、覆盖审计、残余缺口和候选/已准入作品集合**。

**一旦冻结，才启动真正的本体与知识图谱工作。** 未来从新论文、修订或遗漏来更新 Corpus v1.x；对知识体系的修改也应留下审计记录，但不以“永不改动”作为目标。

## 7. 后续统一归纳及界面（冻结后）

在 Corpus v1 的全域可信来源上进行跨学科比较，确定理论概念、方法家族、具体算法/网络/物理模型/训练机制、应用与验证关系。每个重要方法演进关系应回到原始研究定位具体机制，不能靠发表年份、同名关键词和任务相似性推断。

建设数据层后，以**同一套正式学术数据**生成四个互联视角：

1. Taxonomy：概念/家族分类；
2. Lineage：有证据的真实方法演进与机制借用；
3. Problem Pathway：科学与生物医学问题、可用方法及验证边界；
4. Scholarly Library：准入文献与专著、原文证据、章节、方法贡献。

可复用旧版 UI 技术，但学术知识不从旧图谱继承。
