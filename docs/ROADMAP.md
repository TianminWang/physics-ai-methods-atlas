# Roadmap · 物理 AI 方法知识图谱建设路线

**总原则：先保证知识组织结构正确，再增加学术证据，随后开展渐进式可视化。** 新论文和新方法可以持续补充，因此不存在“必须把所有文献找齐以后才准展示”的最终完成点。

## v0.1 / v0.2 — 已完成的历史基础

- [x] 方法、论文、专著、研究问题、领域和有类型关系的统一数据源
- [x] 原有30个方法、32篇论文/章节、8本专著、10个研究问题
- [x] 原始论文与方法贡献关系、优先阅读建议、类型及基础 DAG 校验
- [x] 优先阅读非强制（通常少量，但没有0/1/2篇的强制额度）

## v0.3 — 统一研究主轴 + 方法家族 DAG（本次）

- [x] 六个主轴环节及循环反馈，环节颜色稳定且唯一
- [x] 独立方法家族及多重成员关系，无需把方法固定归属于主轴中的单个环节
- [x] 环节→方法家族/具体方法的双语功能边，写明方法实际提供的能力
- [x] 方法分类与改进/融合关系分离；改进/融合边写明机制、瓶颈、证据、主次关联环节与可选代价
- [x] 五类跨环节可靠性关注点
- [x] 保留原数据，增量扩展兼容 Schema（v2.0.0 / v2.1.0）
- [x] 中文默认首页、英文镜像、双语架构说明与中文方法名翻译层
- [x] 能导出主轴+家族总览和完整方法关系的中英文图谱投影
- [x] 测试/CI 验证主轴角色、演进边、配色、循环和不重复节点

**本阶段没有完成的工作（刻意留给下一阶段）**：大量新增生成式或强化学习论文，完整前端界面。

## v0.4 — 首批方法谱系与文献补强（2026-11-17 已完成）

- [x] 新增31个方法节点，覆盖经典数值离散、反演可辨识性、贝叶斯计算与 SBI。
- [x] 建立 VAE、GAN、Normalizing Flow、DDPM、Score-SDE、Flow Matching 的生成式谱系，以及生成先验、DPS 和物理信息扩散等反问题交叉节点。
- [x] 补充图神经算子、Galerkin Transformer，并区分 MeshGraphNets 与严格的神经算子方法。
- [x] 补充可微物理模拟、PlaNet/Dreamer 世界模型、MPC、MBPO、CQL 等不同决策范式。
- [x] 补充模型失配、广义多项式混沌与贝叶斯实验设计。
- [x] 新增经过核对的论文、经典数值计算专著；建立方法关联、Landmark 贡献及带瓶颈的部分演化边。
- [x] 新增中英文的 [方法谱系综述（中文）](zh/METHOD_GENEALOGY_V04.md) / [English](en/METHOD_GENEALOGY_V04.md)。
- [x] 保持“少量优先阅读”非强制、方法实体不重复、研究主轴颜色独立及自动测试。

**当前规模：** 6个环节、34个家族、61个方法、58篇论文记录、12本专著、15个研究问题、530条有类型关系。收录的是**经过首轮选择的代表性工作**，不是某一科学领域的所有论文。

**仍需持续补全：** 冠脉0D/1D/3D动力学模型、血管结构与观测算子、CFD耦合及可微模拟更多实现、严格的反问题解稳定性谱系、统计可信性比较、世界模型扩展、真实虚拟 PCI 应用与外部临床验证。后续文献可随研究进展逐步进入 Atlas，并不阻碍先开展可视化验证。

## v0.5 — 三分支交互式布局验证（完成首轮测试）

- [x] 使用权威知识库生成传统反问题、神经算子和生成式反问题三条真实方法谱系。
- [x] 实现六环节选择、家族高亮、改进/融合/分类的不同视觉编码。
- [x] 点击方法/关系后查看核心思想、技术瓶颈、证据论文、Landmark 和 Start Here。
- [x] 默认展示核心方法、按需展开全部；支持中英文、搜索、缩放、拖动。
- [x] 导出免服务器的离线 HTML，以及桌面和移动端的 Chromium 截图。
- [x] 已根据首轮视觉截图修复标签遮挡、默认图过密及手机端过度缩小。

**扩大到 v1.0 的条件：** 自动化浏览器测试与数据测试全部通过，读者确认原型具有足够可读性。下一版将把同一语义与交互机制应用于完整数据集，增加多级折叠/聚焦和 GitHub Pages 稳定发布。

## 后续维护

新论文先进行学术筛选，附在已有节点或确有独立创新时创建新节点，重大“演进边”必须记录真实文献证据。阅读建议服务减负，不变成强制课程。任何定期检索/更新都需要具体触发或另行配置计划任务。
