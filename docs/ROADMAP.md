# Roadmap · 物理 AI 方法知识图谱建设路线


> **最新优先路线（2026-11-26）：** 用户确认 [Corpus-first 全域学术检索与准入协议](zh/CORPUS_FIRST_PROTOCOL_V1.md)，替代下文历史版“检索一批→归纳/建图一批”。先完成研究范围 M1–M8 × 生医工应用 A1–A6 的全域检索、独立候选去重、质量审核和覆盖审计，**冻结 Scholarly Corpus v1** 之后才建立正式本体、方法关系与四视角交互。旧61/34不约束检索或新知识结构。当前独立发现性扫描 [63条待审核线索与14方向缺口矩阵](../research/corpus_v1/SEARCH_AND_COVERAGE_2026-11-26.md)，尚未完成全域检索/质控。


> **2026-11-26 B1 实施状态：** [完整执行方案已确认](zh/EXECUTION_PLAN_V09.md)。采用 M1–M8 方法学 × A1–A6 生医工应用的正交检索标签，并保留分类/演进/问题/文献库四视角设想。**B1 已启动**，[首批候选与检索记录](../research/b1/SEARCH_LOG_2026-11-26.md)含 22 篇论文 + 4 本专著，均为待审核；B2/B3/C/D 尚未执行，不将旧数据与发现候选误称正式入选文献。

> **2026-11-26 路线调整（优先于以下历史版本描述）**：采用[学术来源质量准入政策 v1.0](zh/SOURCE_ADMISSION_POLICY.md)，将 **“来源筛选 → 原文归纳 → 学术本体 → 证据关系 → 交互界面”**作为实际建设顺序。当前61方法/34家族/58论文/12专著和 v0.8 UI 为历史原型与测试样本，不等同于已审核的正式知识体系。**v0.9-A 已完成；v0.9-B1 已启动书目发现，B2/B3/C 及正式迁移未实施，按[新的证据驱动重建路线](zh/EVIDENCE_FIRST_REBUILD.md)重新定义任务与验收。** 保留历史成果，不自动沿用旧节点和关系，也不立即删除数据。

**历史路线原则：先保证知识组织结构正确，再增加学术证据，随后开展渐进式可视化。** 新论文和新方法可以持续补充，因此不存在“必须把所有文献找齐以后才准展示”的最终完成点。
